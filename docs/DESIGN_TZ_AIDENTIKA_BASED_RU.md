# ТЗ: Редизайн Mini App в стилистике Aidentika

## Цель

Перевести web app / Telegram Mini App в визуальную систему, близкую к `aidentika.com`:
- современный продуктовый интерфейс;
- чистая бело-черная база;
- яркий lime primary;
- violet accent;
- высокий контраст;
- спокойные поверхности;
- сильная читабельность на desktop и mobile.

## Что входит в этап

### 1. Визуальная система

- шрифт интерфейса `Geist`
- шрифт для технических блоков `Geist Mono`
- единая палитра
- радиусы, рамки, тени
- light / dark versions

### 2. Главный экран Mini App

- hero-блок в Aidentika-style
- переработка первого экрана под один главный сценарий
- акцент на читабельности и CTA
- снижение визуального шума

### 3. Компоненты

- кнопки
- поля формы
- карточки
- аккордеоны
- статусы / badges
- report boxes
- пустые состояния

### 4. Адаптивность

- desktop
- mobile
- Telegram Mini App webview

## Что не входит в этот этап

- изменение бизнес-логики
- переработка backend flow
- новые функциональные сценарии
- аналитика по UX
- новый onboarding flow по логике

## Принципы редизайна

- сначала читаемость, потом декор;
- один главный фокус на экран;
- вторичное уводится в скрываемые блоки;
- контраст текста должен оставаться высоким в light и dark;
- не использовать “случайные красивые цвета”, только дизайн-токены системы.

## Критерии готовности

- интерфейс визуально читается как единая система;
- палитра и шрифты соответствуют выбранному visual direction;
- кнопки и формы выглядят консистентно;
- Telegram light/dark не ломают читаемость;
- mobile layout не разваливается;
- экран воспринимается как продуктовый SaaS UI, а не как набор несвязанных блоков.
