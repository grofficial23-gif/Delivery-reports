# Инструкция Для Команды

## Что Это
`Delivery Reports Bot` помогает быстро собирать рабочие заметки в течение дня и превращать их в черновик daily report.

Бот умеет:
- сохранять обычные текстовые заметки;
- принимать voice и сохранять транскрипт или хотя бы сам факт заметки;
- раскладывать информацию по блокам `Что сделано`, `План / следующий шаг`, `Риски / блокеры`;
- собирать черновик отчета;
- хранить личные задачи PM и неразобранные заметки.

## Как Работать Каждый День
1. Основной режим: откройте Mini App через `/app` или через menu button `Mini App`.
2. Один апдейт = один проект, эпик или отдельный смысловой блок.
3. В течение дня добавляйте апдейты по одному, а не большой стеной текста.
4. Когда нужно понять текущую картину, нажмите `📊 Статус` или напишите `статус`.
5. Когда готовы собрать отчет, нажмите `📋 Собрать отчёт` или напишите `/draft`.
6. Если текст нужно сократить или сместить акцент, используйте `короче`, `акцент на риск` или `/fixdraft`.
7. Когда отчет готов, используйте `/finalize`.

Если чат-режим неудобен, можно работать через Telegram Mini App:
- отправить боту `/app`;
- открыть приложение из кнопки внутри Telegram;
- работать с заметками, задачами, inbox, черновиком и финальным отчетом на одном экране;
- автор подтянется из Telegram-профиля автоматически;
- проекты и история будут видны только вашему аккаунту.

## Самый Простой Сценарий
Просто пишите как человеку:

```text
Caller ID: аналитика завершена, матрицу событий согласовали с Назаром, завтра передаем в разработку
```

или:

```text
DC701: продолжается перенос виртуальных серверов, нужен список некритичных систем, риск по срокам и доступам в новый ЦОД
```

Этого уже достаточно, чтобы бот сохранил заметку и попробовал сам понять проект и смысл.

## Полезные Быстрые Фразы
- `статус` — короткая сводка за день.
- `мои задачи` — показать активные задачи.
- `inbox` — показать неразобранные заметки.
- `черновик` — показать текущий черновик.
- `финальный` — показать финальный отчет.
- `задача: согласовать окно ночных работ` — добавить задачу.
- `готово 12` — отметить задачу выполненной.
- `жду 7` — перевести задачу в ожидание.
- `в работе 5` — перевести задачу в работу.
- `разобрать 15 DC701` — вручную привязать заметку из inbox к проекту.

## Когда Лучше Писать Структурно
Если заметка важная или сложная, лучше писать так:

```text
Проект: DC701
Статус: в работе
Что сделано:
- переносим виртуальные серверы из ГО
- настраиваем backup в новый ЦОД

План:
- согласовать ночные окна

Риски:
- сжатые сроки освобождения старого здания
```

Так бот точнее соберет красивый черновик без ручной правки.
Если укажете `Статус:`, бот сохранит его и постарается перенести в итоговый отчет как есть.

## Как Добавлять Проекты И Эпики
Если бот не знает проект или эпик, можно обучить его прямо в чате:

```text
проект: DC701 | алиасы: цод, новый цод | руководитель: Дмитрий Кононенко
```

```text
эпик: Caller ID | проект: Daily Delivery Report | алиасы: caller id, caller
```

## Личные Настройки
Если нужно сохранить автора и руководителя по умолчанию:

```text
менеджер: Анатолий Графкин
руководитель: Дмитрий Кононенко
```

## Если Бот Ошибся
Если бот не уверен в проекте:
- откройте `inbox`;
- выберите заметку;
- напишите `разобрать <note_id> <проект>`.

Если бот неверно понял последний проект, можно быстро поправить:

```text
не Kaspi, а Онбординг
```

## Основные Команды
- `/start` — начать работу и привязать чат.
- `/app` — открыть личный Telegram Mini App.
- `/pro` — посмотреть тарифы и Premium-возможности.
- `/help` — краткая справка.
- `/status` — сводка за день.
- `/draft` — собрать черновик.
- `/showdraft` — показать текущий черновик.
- `/fixdraft <короче|акцент на риск|обычный>` — перестроить черновик.
- `/template team` — включить командный стиль по живым примерам.
- `/finalize` — зафиксировать финальный отчет.
- `/final` — показать финальный отчет.
- `/task add <текст>` — добавить задачу.
- `/mytasks` — показать задачи.
- `/inbox` — показать неразобранные заметки.

## Практические Советы
- Лучше одно сообщение = один проект или один смысловой блок.
- Если в сообщении много разных тем, разбивайте их на несколько сообщений.
- Если есть Jira key, эпик или явное название проекта, добавляйте их в текст.
- Для сложных апдейтов лучше явно писать `Что сделано`, `План`, `Риски`.
- Если сомневаетесь, просто пишите обычным языком. Бот рассчитан именно на это.

## Рекомендуемый Минимум Для Команды
Если нужен совсем короткий onboarding, достаточно объяснить людям 4 вещи:
1. Основной режим работы: Mini App через `/app`.
2. Один апдейт = один проект или эпик.
3. Для контроля дня нажимайте `📊 Статус`.
4. Для отчета нажимайте `📋 Собрать отчёт`.
