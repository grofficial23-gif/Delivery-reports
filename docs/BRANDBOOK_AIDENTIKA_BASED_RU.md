# Brandbook: Aidentika-Based UI System

## Статус

Этот документ фиксирует дизайн-систему web app на основе публично наблюдаемой стилистики `aidentika.com`.
Он нужен как рабочий брендбук для продукта, чтобы дальше не расползались цвета, шрифты, радиусы и компоненты.

Важно:
- это не юридическое копирование чужого брендбука;
- это адаптированная система на основе публичного visual direction сайта;
- логотипы, уникальные иллюстрации и фирменные графические активы Aidentika сюда не входят.

## Источник визуального направления

- официальный сайт: `https://aidentika.com`
- публичные CSS-токены сайта:
  - `--background: #ffffff`
  - `--foreground: #0a0a0a`
  - `--primary: #a3e635`
  - `--primary-hover: #84cc16`
  - `--accent: #7c3aed`
  - `--border: #e5e5e5`
  - `--muted: #f5f5f5`
  - `--muted-foreground: #737373`
  - `--radius: 12px`
- публичный шрифт интерфейса: `Geist`
- публичный моноширинный шрифт: `Geist Mono`

## Характер интерфейса

- современный продуктовый SaaS-интерфейс;
- очень чистая бело-черная база;
- один яркий основной цвет для CTA;
- один технологичный accent-цвет для secondary emphasis;
- мягкие карточки и тонкие рамки;
- высокий контраст и минимум визуального шума;
- крупная, плотная, очень читаемая типографика.

## Типографика

- Основной UI-шрифт: `Geist`
- Код, превью, технические блоки: `Geist Mono`
- Заголовки:
  - вес: `700`
  - плотный tracking
  - крупный размер
- Основной текст:
  - спокойный ритм
  - line-height около `1.6`
- Акцентные слова:
  - допускается `italic`
  - чаще всего через `primary`

## Скругления и поверхности

- `radius-sm`: `8px`
- `radius-md`: `12px`
- `radius-lg`: `16px`
- `radius-xl`: `20px`
- `radius-2xl`: `24px`

Карточки:
- белые или слегка приподнятые поверхности;
- тонкая рамка;
- мягкая тень;
- без тяжелого стекла и без избыточного blur.

## Принципы композиции

- один главный сценарий на экран;
- второстепенные блоки складываются в accordion / details;
- контент не должен конкурировать с управляющими элементами;
- фон спокойный, а внимание держится на типографике, CTA и карточках.

## Что уже применено в web app

- `Geist` / `Geist Mono`
- бело-черная база
- lime primary CTA
- violet accent
- тонкие рамки и мягкие тени
- dark hero-section в духе Aidentika
- упрощённая иерархия экрана
